# 记录硅谷甄选项目

## 基础配置

### eslint

- 在` "dev": "vite"`后面追加`"dev": "vite --open"` 运行时自动打开浏览器

### husky

在提交代码前触发git hook，然后执行`pnpm run format`自动格式化代码

安装`husky`

```cmd
pnpm install -D husky
```

执行

```cmd
npx husky-init
```

会在根目录下生成一个.husky目录，在这个目录下会有一个pre-commit文件，这个文件里面的命令在执行commit的时候就会执行

### 配置commitlint

统一规范commit信息，让每个人都按照统一的标准来执行
安装：

```cmd
pnpm add @commitlint/config-conventional @commitlint/cli -D
```

添加配置文件,新建commitlint.config.cjs(注意是**cjs**),然后添加下面的代码

```ts
module.exports = {
  extends: ['@commitlint/config-conventional'],
  // 校验规则
  rules: {
    'type-enum': [
      2,
      'always',
      ['feat', 'fix', 'docs', 'style', 'refactor', 'perf', 'test', 'chore', 'revert', 'build'],
    ],
    'type-case': [0],
    'type-empty': [0],
    'scope-empty': [0],
    'scope-case': [0],
    'subject-full-stop': [0, 'never'],
    'subject-case': [0, 'never'],
    'header-max-length': [0, 'alwways', 72],
  },
}
```

在package.json中配置scripts命令

```cmd
# 在scripts中添加下面的代码
{
  "scripts": {
    "commitlint": "commitlint --config commitlint.config.cjs -e -v"
  }
}
```

配置结束，当填写commit信息的时候，需要带着下面的subject

```
'feat',//新特性、新功能
'fix',//修改bug
'docs',//文档修改
'style',//代码格式修改，注意不是css修改'refactor',//代码重构
'perf',//优化相关，比如提升性能、体验
'test',//测试用例修改
'chore,//其他修改，比如改变构建流程、或者增加依赖库、工具等
'revert',//回滚到上一个版本
'bui1d',//编译相关的修改，例如发布版本、对项目构建或者依赖的改动
```

在cmd中执行

```cmd
npx husky add .husky/commit-msg
```

会在.husky文件下出现一个comit-msg文件，替换为

```
#!/usr/bin/env sh
. "$(dirname -- "$0")/_/husky.sh"

pnpm run format

```

### 阿里svg图标库

1. 安装插件：`pnpm install vite-plugin-svg-icons -D`
2. 在`vite-config.ts`中的defaultConfig.plugins引入(plugins是数组，所以直接追加配置即可)

```ts
  plugins: [
    vue(),
    vueDevTools(),
    createSvgIconsPlugin({
      iconDirs: [path.resolve(process.cwd(), 'src/assets/icons')], // 将图标放入的位置
      symbolId: 'icon-[dir]-[name]',
    }),
  ]
  ....
```

3. 在入口文件(`main.ts`)中引入

```ts
import 'virtual:svg-icons-register'
```

4. 可能出现的情况报错情况:找不到`svg-icons-register`
   在tsconfig.json下的`env.d.ts`文件中添加

```ts
// 手动为它添加一个类型声明，告诉 TS 编译器这个模块是存在的
declare module 'virtual:svg-icons-register' {
  const component: any
  export default component
}
```
